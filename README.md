## 🕹 Установка и запуск
1. Склонируйте репозиторий:
   ```bash
   git clone git@github.com:varvar-var/flappy_bird_game.git
   cd flappy_bird_game
   ```

2. Установите Pygame (и другие зависимости):
   ```bash
   pip install pygame
   ```

3. Запустите игру:
   ```bash
   python main.py
   ```

## 🖥 Системные требования
- ОС: Windows / macOS / Linux
- Python 3.6+
- Разрешение экрана: 900x600 (можно изменить в коде)
